GOOD TO KNOW

A few quick answers.

Is this the official college ERP app?

No. FeedbackGo is an independent student utility, not an official app from your college or ERP provider.

Does FeedbackGo replace ERP login?

No. You continue signing in through the ERP using its usual password, captcha and OTP steps.

Can it automatically submit feedback?

Live feedback filling and submission are not yet enabled. Those features require testing when ERP forms are available.

Is it safe to install an APK?

Only install from a GitHub Release you trust. Check the publisher and never disable Android security protections to force an install.
